Nova análise

Comece pelo identificador do artigo. O sistema busca os metadados automaticamente na Crossref e mostra o cartão para você conferir antes de salvar. Caso o artigo não tenha DOI, é possível avançar digitando os dados manualmente.

Lookup por ISBN não está neste mockup — a tela final usaria OpenLibrary ou Google Books. Selecione Tenho DOI para ver o fluxo de preview.
Sem identificador, o sistema gera um identificador interno legacy:HASH(título|ano|periódico). Os campos abaixo precisam ser preenchidos manualmente.
