{% comment %} Componente Alpine `editorAnalise(url, resenhaUrl)` para o editor de análise. Abas (identificação / presença / estrutura) são alternadas NO CLIENTE — sem recarregar a página, então trocar de aba nunca perde dados. O auto-save persiste em segundo plano: - com debounce ~1.2s após digitar (@input); - ao sair de um campo (focusout); - ao trocar de aba (flush); - a cada 30s como rede de segurança. `beforeunload` avisa se houver pendência ao sair de fato da página (fechar aba, URL, resenha). A resposta do save traz `faltantes`, atualizando o bloco de submissão ao vivo. Estado exibido por templates/acervo/_autosave_status.html. {% endcomment %}
